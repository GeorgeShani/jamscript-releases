# JamScript desktop releases

Official installers and signed updates for [JamScript](https://jamscript.dev).

- [Latest stable download](https://github.com/GeorgeShani/jamscript-releases/releases/latest)
- Updater-enabled versions provide an **Updates** button inside the app.
- Windows: EXE or MSI. macOS: Apple Silicon DMG. Linux: AppImage or DEB.
- Linux in-app updates use the AppImage edition. Older versions require one manual installation of an updater-enabled release.

Every release includes the corresponding source archive, build instructions, dependency lockfiles, and license notices. Development history lives in a separate source repository. JamScript is distributed under AGPL-3.0; see the source archive's LICENSE and THIRD_PARTY_NOTICES.txt.

Windows installers are unsigned. macOS builds are ad-hoc signed and not notarized. Update packages are independently signed and verified by the application.

Never install an update from a different repository or share your credentials with a purported update service.
